# «Разъём» — интернет-магазин электроники

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина электроники и компьютерных аксессуаров «Разъём». Магазин, товары, адрес и телефоны вымышленные: заказы не обрабатываются, данные форм никуда не отправляются.

## Используемые технологии

- HTML5: семантическая разметка, формы, таблицы, `<dialog>`, `<details>`;
- CSS3: переменные, Flexbox, Grid, `:has()`, `:target`, CSS-счётчики, медиазапросы;
- JavaScript: только минимальная логика модальных окон и проверки формы (`js/main.js`);
- Git и GitHub, GitHub Pages.

CSS-фреймворки и сторонние библиотеки не используются. Шрифты системные, все изображения — локальные SVG-иллюстрации в папке `images/`.

## Как посмотреть проект

1. Скачайте или клонируйте репозиторий.
2. Откройте файл `index.html` в браузере (Chrome, Edge, Firefox или Safari последних версий).

Сервер не нужен: все страницы работают при открытии файлов напрямую.

## Страницы сайта

| Страница | Содержимое |
|---|---|
| `index.html` | Hero-блок с иллюстрацией товара и выносками характеристик, преимущества (`#advantages`), популярные товары (`#popular`), разделы каталога, отзывы (`#reviews`), вопросы и ответы (`#faq`), контакты (`#contacts`) |
| `catalog.html` | 9 карточек товаров на CSS Grid, боковая панель фильтров (`aside`, `position: sticky`), счётчик найденных товаров, хлебные крошки |
| `product.html` | Изображение, цена, наличие, преимущества, описание, таблица характеристик, кнопка заказа, хлебные крошки, таблица способов доставки |
| `order.html` | Форма заказа: имя, e-mail, телефон, товар или тема, количество, способ получения, комментарий, согласие на обработку данных; блок «Что будет дальше» |
| `contacts.html` | Телефон, почта, адрес, часы работы, схема проезда, ссылки на разделы, модальное окно «Заказать обратный звонок» |

На всех страницах одинаковые шапка с меню, подвал и кнопка «Наверх», уникальные `title` и `meta description`.

## Как выполнены требования

- **Семантика:** `header`, `nav`, `main` (один на странице), `section`, `article` (карточки товаров, контакты), `aside` (фильтры, этапы заказа, доставка), `footer`, а также `figure`/`blockquote` для отзывов, `address`, `dl`.
- **Навигация:** единое меню с активным пунктом (`site-nav__link--active` и `aria-current="page"`), якорные ссылки на разделы главной страницы в подвале и в hero-блоке, хлебные крошки.
- **Карточки товаров:** название, описание, цена, кнопка «Подробнее», бейджи «Хит», «Новинка», «Скидка», «Нет в наличии».
- **Таблица:** `caption`, `thead`, `tbody`, `th` (с `scope`), `td`; полосатые строки и подсветка строки при наведении.
- **Форма:** у каждого поля есть `label` с совпадающими `for`/`id`, атрибуты `name`, `required`, `type="email"`, `type="tel"` с `pattern`, `minlength`, `min`/`max`.
- **Модальные окна:** `<dialog>` — открываются кнопкой, закрываются кнопкой «×», клавишей Escape и кликом по затемнённому фону.
- **CSS:** блок `:root` с переменными цветов, шрифтов, отступов, скруглений и слоёв `z-index`; состояния `:hover`, `:focus-visible`, `:disabled`, `:active`.
- **Flexbox:** шапка, меню, группы кнопок, подвал карточки, варианты способа доставки.
- **Grid:** сетка карточек (`repeat(auto-fill, minmax(240px, 1fr))`), раскладка каталога «фильтры + товары», блок разделов на `grid-template-areas`, страница товара, форма, подвал.
- **БЭМ:** блоки `site-header`, `site-nav`, `product-card`, `filters`, `order-form`, `spec-table`, `modal` и др.; элементы `product-card__title`, `order-form__input`; модификаторы `product-card--sale`, `product-card--hit`, `product-card--out-of-stock`, `button--secondary`, `site-nav__link--active`.
- **Позиционирование:** `relative` — карточка товара и hero-блок; `absolute` — бейджи и выноски характеристик; `sticky` — шапка, фильтры каталога, блок этапов заказа; `fixed` — кнопка «Наверх»; `z-index` — шапка, бейджи, кнопка «Наверх».

## Самостоятельные доработки

1. **Рабочие фильтры каталога без JavaScript.** Категории и флажки «Только со скидкой», «Только в наличии» скрывают карточки через селектор `:has()`. Количество найденных товаров считает CSS-счётчик: скрытые карточки не учитываются. Кнопка «Сбросить фильтры» — обычный `type="reset"`.
2. **Страница для каждого товара без дублирования файлов.** Все 9 товаров находятся в `product.html`, а нужный показывается псевдоклассом `:target` (например, `product.html#klavo-75`). Без якоря показывается товар по умолчанию.
3. **Собственный визуальный стиль.** Акцентный зелёный цвет печатной платы, технический шрифт заголовков Bahnschrift, hero-блок в виде чертежа с выносками характеристик, собственные SVG-иллюстрации товаров.
4. **Варианты карточек через БЭМ-модификаторы:** скидка (красная цена и старая цена), хит, новинка, «нет в наличии» (приглушённое изображение, на странице товара — неактивная кнопка `disabled`).
5. **Дополнительные разделы:** разделы каталога, отзывы покупателей, вопросы и ответы на `<details>`, блок «Что будет дальше» на странице заказа, схема проезда, таблица способов доставки.
6. **Улучшенный сценарий заявки.** Ошибки показываются под полями и исчезают сразу после исправления; фокус переходит на первое поле с ошибкой. После успешной проверки открывается модальное окно с подтверждением. Кнопка «Оформить заказ» на странице товара сразу выбирает этот товар в форме (`order.html?product=...`), а ссылки разделов с главной отмечают нужную категорию в фильтре.
7. **Доступность:** ссылка «Перейти к содержимому», видимый фокус у всех элементов, `aria-current` для текущей страницы, `aria-invalid` и `aria-describedby` для ошибок формы, подписи у всех полей, `alt` у изображений, учёт `prefers-reduced-motion`.
8. **Адаптивность:** три раскладки (компьютер, планшет до 1024 px, смартфон до 720 px); на смартфоне меню прокручивается по горизонтали.
9. **Кнопка «Наверх»** с `position: fixed`; в браузерах с поддержкой scroll-driven animations она появляется только после прокрутки.

## Роль JavaScript

По методическим указаниям КР №1 оценивается как HTML/CSS-проект, поэтому JavaScript использован минимально. Файл `js/main.js`:

- открывает и закрывает модальные окна `<dialog>`;
- выводит понятные сообщения об ошибках формы и показывает окно подтверждения;
- подставляет товар в форму заказа и категорию в фильтр по параметру адреса;
- прокручивает страницу наверх без изменения якоря (иначе на `product.html` сменился бы показанный товар).

Если JavaScript отключён, фильтры, FAQ, страница товара и навигация продолжают работать, а форма проверяется встроенной HTML-валидацией браузера.
